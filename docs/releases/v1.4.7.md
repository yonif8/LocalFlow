# LocalFlow 1.4.7

## Changes

- Settings → Dictation now has a **Lower to** slider for "Lower other audio
  while dictating". Choose any level from 0% to 100% in 5% steps; 0% mutes
  other audio while you hold the shortcut. The default stays at 20%, so
  existing setups behave as before.
- Ducking now means the same thing on every platform: output drops *to* the
  chosen level and quieter audio is never turned up. Windows previously
  scaled the current volume by 20%, and Linux could raise a quieter sink to
  20%.
- On macOS, 0% uses the output device's mute switch when it has one (a volume
  of zero is not fully silent on every device). If you had already muted,
  LocalFlow leaves it muted.
- Bug reports include the ducking setting.

## Updating

Use **Check for Updates** on macOS or Windows, or the in-app updater for the
recommended Linux AppImage. Debian/Ubuntu DEB users download and install the
new package manually.

## Validation scope

The macOS suite and a live Mac run cover the new setting. Windows/Linux
changes are covered by the automated release gate; hands-on Windows/Linux
testing remains deferred until those machines are available. See
[feature parity](../FEATURE_PARITY.md).
