# LocalFlow 1.4.6

## Changes

- Removed the experimental call-transcription feature. Existing saved data is
  left untouched.

- Long push-to-talk dictations now transcribe and polish in the background at
  natural pauses on macOS, Windows and Linux. Short dictations remain one pass.
- Chunk sizing starts from measured processing times and adapts downward when
  processing is slower, aiming for about two seconds from release to insertion.
  This is an aim, not a guaranteed deadline: continuous speech, noise, slower
  hardware and recovery can take longer.
- The last recognized sentence carries into the next chunk. Nothing is inserted
  before release; cancellation discards the pending result. Failed background
  work retries from retained audio instead of inserting a partial transcript.
- Fixed a macOS crash when unusually long screen terms expanded beyond the
  terminology matcher's supported word span.
- Updated polish defaults to stop skipping normal longer messages at 700
  characters. Diagnostic logs record stages and counts rather than transcript text.

## Updating

Use **Check for Updates** on macOS or Windows, or the in-app updater for the
recommended Linux AppImage. Debian/Ubuntu DEB users download and install the
new package manually. The free distribution/signing arrangements are unchanged.

## Validation scope

Mac testing includes actual microphone capture, background processing, final
insertion, cancellation and a subsequent short dictation. Two long local tests
completed insertion about 0.32 seconds after release. That figure is specific
to this test machine and speech, not a Windows/Linux performance promise.

87 Swift tests, 67 portable C++ core tests, six incremental scenarios and Qt
sentence-boundary tests cover the changes. Publishing requires the automated
Windows/Linux build, model, packaging and signed-update release gates.
Hands-on Windows/Linux microphone, shortcut and desktop testing remains deferred
until those machines are available. See [feature parity](../FEATURE_PARITY.md)
and [incremental dictation details](../INCREMENTAL_DICTATION.md).
