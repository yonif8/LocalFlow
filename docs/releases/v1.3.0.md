# LocalFlow 1.3.0

Published 2026-09-04. Documentation updated 2026-09-05; application binaries,
the release tag, checksums, signatures, and update feeds are unchanged.

LocalFlow now has public macOS, Windows, and Linux downloads in one repository
and release. Hold a shortcut, speak, and release to insert text, with local
Parakeet speech recognition, optional S1-mini polishing, screen terminology,
an editable terminology bank, history, settings, and tray/menu bar controls.

## Download and install

- [macOS DMG](https://github.com/yonif8/LocalFlow/releases/download/v1.3.0/LocalFlow-1.3.0.dmg):
  Apple Silicon, macOS 15+. Drag into Applications. The free self-signed,
  non-notarized app may need **Privacy & Security → Open Anyway** at first launch.
- [Windows EXE](https://github.com/yonif8/LocalFlow/releases/download/v1.3.0/LocalFlow-1.3.0-windows-x64-setup.exe):
  Windows 11 x86-64; per-user installation without administrator access.
  The free installer has no Authenticode certificate, so Windows may display
  **Unknown publisher** or SmartScreen. Use **More info → Run anyway** if offered
  for the official download; managed security policies may block it.
- [Linux AppImage](https://github.com/yonif8/LocalFlow/releases/download/v1.3.0/LocalFlow-x86_64.AppImage):
  x86-64, packaged on Ubuntu 22.04. Make it executable and run it.
- [Linux DEB](https://github.com/yonif8/LocalFlow/releases/download/v1.3.0/localflow_1.3.0_amd64.deb):
  alternative for Debian/Ubuntu package installation.

See the [installation guide](https://github.com/yonif8/LocalFlow#install) for
permissions, model setup, and optional Linux desktop integration. Windows/Linux
download about 1.2 GB of local models during setup. No Windows or Linux ARM64
packages are included.

## Updates and limitations

macOS uses Sparkle. Windows checks installer integrity with LocalFlow's pinned
Ed25519 release key independently of Authenticode. Linux AppImage verifies signed
in-app updates; DEB installations use manual package updates from Releases.

**Hands-on Windows/Linux certification is pending.** Automated testing passed,
but everyday use across real applications and desktop environments has not
been fully certified. At the owner's request, that testing is deferred until
Windows/Linux machines are available.

- Windows screen capture uses GDI. Windows Graphics Capture is not implemented;
  some GPU-rendered surfaces may produce incomplete screen terminology.
- Windows elevated/protected targets can restrict insertion.
- Wayland depends on desktop portals and app accessibility. Global mouse
  triggers, Escape cancellation, tray behavior, and inaccessible target apps
  have limitations. GNOME/KDE/Fedora combinations are not individually certified.
- Sharing a repository does not automatically enforce behavior parity between
  the macOS Swift app and the Windows/Linux C++ app. Future features require
  implementation and validation in every affected edition.

  exact v1.3.0 commit; build/tests, real-model inference, staged runtime,

- [Linux production run](https://github.com/yonif8/LocalFlow/actions/runs/33864775367):

- macOS local release build: 76 tests passed; pinned Metal library built;
  app signature, DMG checksum, and Sparkle Ed25519 signature verified.
  The [merged-source macOS CI](https://github.com/yonif8/LocalFlow/actions/runs/33863297187)
  is separate from the final tag's local packaging evidence.
- All 12 public asset digests matched the assembled files at publication.

The [combined release workflow](https://github.com/yonif8/LocalFlow/actions/runs/33864663332)
stopped because its token could not inspect the private draft. The Windows and
Linux production workflows were then run separately against the unchanged tag;
their verified artifacts were assembled with the macOS files and published.
The combined workflow did not pass and must not be cited as successful.
Draft-validation permissions were corrected afterward on main; the full
combined draft-to-public path still needs to be exercised for a future release.

Outstanding hands-on checks include microphone/shortcut behavior, screen OCR,
insertion and clipboard restoration in real apps, audio restoration,
onboarding, launch at login, offline operation, and complete update rehearsal.
See the [feature parity contract](https://github.com/yonif8/LocalFlow/blob/main/docs/FEATURE_PARITY.md).
